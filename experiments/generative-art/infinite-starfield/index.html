About Infinite Starfield

This experiment creates a procedurally generated universe using seeded random number generation. Each "cell" of space generates the same stars every time, allowing for infinite exploration while maintaining consistency.

Technical Details

The starfield uses a technique called "spatial hashing" combined with seeded RNG (Random Number Generation). Space is divided into cells, and each cell's seed is based on its coordinates. This ensures that zooming out and back in will always show the same stars.

Stars are rendered using additive blending to create realistic glow effects. Larger stars have brighter cores with soft halos.
