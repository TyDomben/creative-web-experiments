About Particle Typography

This experiment samples text and converts each pixel into an autonomous particle agent. These particles have behaviors like seeking their home position, avoiding the mouse, and responding to forces.

Technical Details

Uses HTML5 Canvas to render text, samples pixel data using getImageData(), then creates a particle system where each particle uses steering behaviors (seek, flee, cohesion) to create emergent motion patterns.

Particles use verlet integration for smooth physics and implement flocking behaviors inspired by Craig Reynolds' Boids algorithm.

Interaction Guide

  • Type Text - Press E to enter new text
  • Mouse Move - Repel particles
  • Click - Explosive force
  • E - Edit text
  • C - Cycle color modes
  • Space - Reset to formation
  • S - Save image

Color Modes

Cycle through rainbow, monochrome, velocity-based, and position-based coloring by pressing C.

Inspiration
