🕌 Recursive Patterns

Generate infinite Islamic and geometric patterns using recursive algorithms. Each pattern is built from simple shapes repeated and transformed in mathematically precise ways.

Controls:

  • Choose pattern type from sidebar
  • Adjust depth/complexity
  • Change colors and rotation
  • Spacebar to animate

Recursive Patterns

Islamic geometric patterns are based on mathematical principles of symmetry and repetition. This experiment generates patterns using recursive subdivision and transformation.

Pattern Types

Islamic: Traditional star and polygon patterns
Mandala: Circular symmetry patterns
Celtic: Interwoven knot patterns
Fractal: Self-similar recursive shapes
Tessellation: Space-filling patterns

Mathematics

Uses rotational symmetry, recursive subdivision, and affine transformations. Each level multiplies complexity exponentially.
